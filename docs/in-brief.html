GitHub Control Hub

It keeps its own copy of the organization, and sends your changes out under your name.

A desktop app watching a GitHub organization and an AWS account. Five things explain most of how it behaves.

How it works

01

It walks the whole GitHub API once a night

Every repository, team, member, branch and collaborator, read again from scratch, so what the app knows about the organization does not drift away from what is actually there. A lighter pass covers the fast-moving parts every thirty minutes.

02

Every screen reads what that walk collected, not GitHub

Which is the whole reason a tab opens immediately. Asking GitHub directly would mean several hundred API calls per screen, and you would wait for all of them. The trade is that answers are as fresh as the last update, not as fresh as this second, so every screen says when it was last refreshed.

03

GitHub tells it when something changes

A webhook arrives within seconds of a change on github.com and updates just the part it affects, so what you see is usually current rather than a night old. The nightly walk is there to catch whatever a missed delivery would otherwise leave wrong forever, not to be the main way things stay up to date.

04

Your changes go out as you

When you change branch protection, a repository setting or anything else through the app, the call is made with your own GitHub sign-in, not with a service account. If GitHub would refuse you, it refuses the app.

The app does hold credentials of its own, but they are for reading in the background: the nightly walk, and receiving webhooks. The one thing they write is the reminder comment on a pull request, which has to come from a consistent account rather than from whoever happened to press the button.

05

AWS is the same arrangement

You sign in with an AWS profile and the app uses it. It reads the account through those credentials and can only change what they already allow. The guardrail rules are set to report by default and enforce nothing until somebody turns that on for a specific rule.

Answers most of what would otherwise mean opening one repository at a time, and a few things github.com has no page for at all, such as everything one person can reach and how they got it.
